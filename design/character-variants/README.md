# Courier character exploration

Open [contact-sheet.html](contact-sheet.html) for a zoomable comparison, or [contact-sheet-final.png](contact-sheet-final.png) for a static review image. The eighteen numbered, individually named PNG files are transparent sprite concepts. No playable code uses them.

## Strongest candidates

- **01 Ember Scout:** the red cape reads clearly against the blue and teal village, and the large right-hand lantern survives the tile preview. Closest to the current courier's red cape and blue clothing.
- **03 Canal Pilot:** compact silhouette, strong navy/cream contrast, and a lantern that remains separate from the body. Good fit for canal and winter chapters.
- **07 Rooftop Finch:** distinctive feather hood and large side satchel make it identifiable even at a glance. The lamp remains clear; the hood may need simplifying for final sprite scale.
- **15 Lantern Keeper:** strongest light-source emphasis and a different age/shape identity. The broad lantern could work especially well in the Night view, though the full body will need further simplification.

## Production notes

These are single-pose concept cutouts, not animation-ready sprites. Test the chosen design in all three game views, then create consistent directional poses and walk frames. Clean stray small details before reducing to the final in-game pixel size. The sample tile in the contact sheet is a visual scale check, not an in-game integration test.
